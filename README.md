# NETWORKWALKS-B084J-WK2-SUBMISSION

### Project overview
This the second lab assignment for the NetworkWalks' Cybersecurity programme. The goal of the project is to perform the first two step of the penetration testing   process ( reconnaissance/footprinting and network scanning) on Networkwalks’ web domain and my Local Area Network. The results of these procedures were then Included in a penetration testing report.
Submission consists of the following:
• Screenshots of the commands used for reconnaissance
• Graph of a network scan, generated using Zenmap
• Penetration testing report 
### Objectives:
• Use the following tools to gather information on a website: whois, whatweb, nslookup, curl, watw00f and dnsrecon

• Use theHarvester to automatically collect publicly available IP addresses, subnets, public profiles and host addresses that can be used as cyber attack vectors

• Install and use ZenMap to scan and generate a graphic representation of a Local Area Network

• Document all the information gathered through the previous objectives in a penetration testing report
